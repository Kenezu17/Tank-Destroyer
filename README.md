# Tank Destroyer

Tank Destroyer is a 2D single-player arcade tank game developed using **Python** and **Pygame**. Players control a battle tank and fight against AI-controlled enemy tanks across five increasingly difficult levels. The game includes collectible power-ups, strategic combat, and progressively stronger enemies.

## 🎮 Features

- 🚜 Player-controlled tank
- 🤖 AI-controlled enemy tanks
- 🗺️ 5 challenging levels
- ⚡ Speed Boost power-up
- 💥 Super Bullet power-up
- 🛡️ Shield power-up
- ❤️ Health system
- 💣 Explosion effects
- 🎵 Background music and sound effects
- 📈 Progressive difficulty
- 🏆 Victory and Game Over screens

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or later
- Pygame

### Installation

```bash
git clone https://github.com/yourusername/tank-destroyer.git

cd tank-destroyer

pip install -r requirements.txt
```

### Run the Game

```bash
python main.py
```

## 🎮 Gameplay

Destroy all enemy tanks to advance through five levels. Enemy AI becomes more aggressive as you progress. Collect power-ups to gain temporary advantages and survive increasingly difficult battles.

## 🎁 Power-Ups

- ⚡ **Speed Boost** – Increases tank movement speed for a limited time.
- 💥 **Super Bullet** – Fires stronger bullets that deal more damage.
- 🛡️ **Shield** – Provides temporary protection from enemy attacks.

## 🤖 Enemy AI

Enemy tanks are controlled by the computer and can:

- Patrol the battlefield
- Detect and chase the player
- Shoot at the player
- Increase in difficulty each level

## 🗺️ Levels

| Level | Description |
|-------|-------------|
| 1 | Basic enemy tanks |
| 2 | Faster enemy movement |
| 3 | Improved enemy accuracy |
| 4 | More enemies and stronger attacks |
| 5 | Final challenge with the toughest AI |

## 🎮 Controls

| Key | Action |
|------|--------|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |
| Space | Shoot |
| P | Pause |
| Esc | Exit Game |
